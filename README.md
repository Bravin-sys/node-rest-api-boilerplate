# node-rest-api-boilerplate

A lightweight, production-ready REST API starter built with Node.js, Express, and TypeScript.

## Features
- TypeScript support out of the box
- Express.js routing structure
- Environment variable management with dotenv
- Input validation middleware
- Error handling and logging
- Ready for PostgreSQL or MongoDB integration

## Tech Stack
Node.js · TypeScript · Express.js · REST API

## Getting Started
```bash
git clone https://github.com/[yourusername]/node-rest-api-boilerplate
cd node-rest-api-boilerplate
npm install
npm run dev
